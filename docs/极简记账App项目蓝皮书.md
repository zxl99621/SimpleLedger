## 1. 项目概述

### 1.1 项目背景与目标

个人自用 Android 记账工具，用于日常收支记录与消费统计。项目以「二次开发 + 学习」为核心目标：在蜜蜂记账开源项目基础上裁剪冗余功能、定制极简风格、扩展本地 AI 能力，最终产出可自用的 APK 安装包；开发过程以 AI 辅助编码，本人负责代码阅读、理解、验证，渐进式学习 Flutter 开发、端侧 AI 集成、移动端本地存储技术。

### 1.2 项目定位

- **类型**：个人财务记账工具
- **平台**：仅 Android，暂不考虑 iOS
- **使用对象**：个人自用
- **核心特色**：本地优先、隐私优先、内置 AI 辅助、极简功能
- **源码策略**：源码公开（source-available），禁止商用

### 1.3 开发模式

- 编码：AI 生成具体代码，本人审查、调试、验证
- 节奏：渐进式迭代，先跑通基础，再逐步叠加能力
- 重心：功能实现 + 架构理解 + 技术学习并重

### 1.4 核心约束

| 约束项 | 指标 |
|--------|------|
| 最低 Android 版本 | Android 11（API 30） |
| 基础 APK 体积 | ≤ 50 MB（不含大语言模型） |
| 模型体积 | 下载页明确标注各模型大小，用户自行决定存储占用 |
| 数据策略 | 纯本地存储，无强制云同步 |
| 源码协议 | BSL 商业源代码许可证，禁止商用 |

## 2. 需求规格说明书

### 2.1 包含范围（必须实现）

#### 基础记账

1. 收支录入：金额、收支类型（收入/支出）、分类、交易日期
2. 扩展字段：简短备注、图片附件、自定义标签（支持多标签）
3. 录入交互：弹窗式记账，核心字段默认展开，备注/图片/标签折叠至「更多」面板
4. 快捷入口：桌面长按 App 图标，快速唤起拍照记账、相册图片记账

#### 统计分析

1. 时间筛选：本周 / 本月 / 自定义时间段
2. 图表：支出分类饼图、月度收支趋势柱状图
3. 列表：分类消费排行、当前周期账单明细列表
4. 同比环比：本期收支、环比（vs 上期）、同比（vs 去年同期）数值卡片，确定性计算展示
5. 首页展示：总资产卡片（可通过设置开关隐藏）、本期收支概览、最近交易列表

#### 数据管理

1. CSV 导入导出：本 App 自有格式，用于查看与跨设备迁移（辅助手段）
2. 完整备份/恢复：数据库文件 + 图片文件夹打包 zip，一键完整备份与恢复
3. 本地持久化：账单、标签、配置全部本地存储
4. 一键清空：清除全部本地数据
5. 桌面小组件：4×2 横版规格，显示本月总支出，点击跳转记账页面

#### AI 能力

1. 图片 OCR 识别账单：云端 API 模式，独立开关，图片附件功能不受 API 影响
2. 自然语言文本记账：一句话解析生成账单记录
3. 月度消费总结：按周期生成文字版消费总结
4. 消费洞察：识别高消费类目，给出简单消费习惯分析（基于确定性计算的同比环比数据做文字解读）
5. 账单问答：自然语言查询历史账单数据
6. 双推理模式：文字类 AI 统一支持「本地离线模型 / 云端 API」切换，用户自主选择
7. 首次使用引导：首次进入 AI 功能时引导用户选择推理模式，不静默默认

#### UI 与体验

1. 底部导航 5 个 Tab：首页 → 统计 → 记账（居中） → AI → 设置
2. 主题：支持浅色 / 深色 / 跟随系统
3. 通用设置：字体大小调节、首页总资产开关
4. 语言：仅中文，不做国际化

❌ 多账本管理

## 5. AI 模块详细设计

### 5.1 整体架构：双模式混合推理

```
用户请求
    ↓
统一 AI 调度层
    ↓
┌─────────────────────────────────┐
│ 推理模式开关（用户配置）          │
├───────────┬─────────────────────┤
│ 本地模型   │ 云端 API            │
│ 离线运行   │ 需要联网 + 用户 Key  │
│ 隐私优先   │ 能力更强            │
└───────────┴─────────────────────┘
    ↓
返回结构化结果 / 自然语言回答
```

- 文字类 AI（记账解析、总结、洞察、问答）统一走调度层，支持两种模式切换
- 图片 OCR 识别独立链路，仅云端 API 模式，不受全局推理模式影响
- 首次使用引导：首次进入 AI 功能时弹窗引导用户选择推理模式（本地模型 / 云端 API），说明各自特点，用户选择后记住，后续不再静默提示

### 5.2 AI 功能矩阵

| 功能 | 本地模型支持 | 云端 API 支持 | 入口 |
|------|-------------|--------------|------|
| 自然语言记账解析 | ✅（随模型能力变化） | ✅ | 记账弹窗顶部输入框 |
| 月度消费总结 | ✅（随模型能力变化） | ✅ | 统计页按钮 |
| 消费洞察 | ✅（随模型能力变化） | ✅ | 统计页按钮 |
| 账单问答 | ✅（随模型能力变化） | ✅ | AI 页面对话 |
| 图片 OCR 账单识别 | ❌ | ✅ | 记账弹窗图片附件 |

> 注：本地模型能力取决于用户下载的模型参数量，0.6B 适合简单记账解析，1.5B/3B 可胜任总结、洞察、问答。

### 5.3 本地模型方案

1. **推理引擎**：llama.cpp，端侧推理，通过 flutter-llama.cpp 插件与 Flutter 集成
2. **模型格式**：GGUF 量化版，生态广泛，几乎所有开源模型均有 GGUF 版本
3. **可选模型列表**（下载页标注体积与推荐用途）：

| 模型 | 量化 | 体积约 | 推荐用途 |
|------|------|--------|----------|
| Qwen3-0.6B | 4bit | ~500MB | 快速记账解析，低性能设备 |
| Qwen3-1.5B | 4bit | ~1.0GB | 均衡之选，总结/问答可用 |
| Qwen3-3B | 4bit | ~2.0GB | 高质量，洞察/复杂问答更佳 |

4. **分发策略**：不打包进 APK，App 内提供下载入口，按需下载
5. **存储位置**：App 私有沙箱目录，其他应用不可访问，卸载同步清除
6. **版本管理**：进入 AI 设置页检测模型列表更新，用户手动下载/切换/删除，不自动下载、不自动删除旧版本
7. **模型切换**：用户可在已下载模型间自由切换，切换后下次推理生效

### 5.4 云端 API 方案

1. **接口标准**：统一采用 OpenAI 兼容接口格式，用户填写「接口地址 + API Key + 模型名」即可接入
2. **兼容服务商**：DeepSeek、通义千问、智谱 GLM、Moonshot、OpenAI 等所有提供 OpenAI 兼容接口的服务商
3. **Key 管理**：用户手动输入 API Key，通过 Android Keystore 生成密钥加密，密文存储在本地配置中，不落明文；本地模型模式下不涉及 API Key
4. **网络策略**：仅用户主动触发 AI 功能时发起请求，无后台静默调用
5. **数据范围**：仅发送当前功能必需的账单文本数据，不附带额外用户信息
6. **隐私提示**：使用云端模式前明确提示用户数据将发送至模型服务商，由用户自主选择

### 5.5 数据安全与隐私

- 本地模式：所有计算在设备内完成，账单数据不出设备
- 云端模式：明确提示用户数据将发送至模型服务商，由用户自主选择是否使用
- API Key：Android Keystore 生成 AES 密钥，用该密钥加密 API Key 后将密文存入本地，Keystore 内密钥不可导出

## 6. 数据存储方案

### 6.1 数据库设计

**账单主表（bills）**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 主键 |
| amount | REAL | 金额 |
| type | TEXT | 收入/支出 |
| category | TEXT | 分类 |
| date | TEXT | 交易日期 |
| note | TEXT | 备注 |
| image_path | TEXT | 图片路径 |
| created_at | TEXT | 创建时间 |

索引：date、category、type

**标签表（tags）**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 主键 |
| name | TEXT | 标签名称 |
| created_at | TEXT | 创建时间 |

**账单标签关联表（bill_tags）**

| 字段 | 类型 | 说明 |
|------|------|------|
| bill_id | INTEGER | 外键 → bills.id |
| tag_id | INTEGER | 外键 → tags.id |

联合主键 (bill_id, tag_id)，tag_id 建索引。标签使用次数通过 `COUNT(*)` 实时计算，不冗余存储。

**配置表（configs）**

| 字段 | 说明 |
|------|------|
| theme_mode | 主题模式 |
| show_total_asset | 总资产显示开关 |
| font_size | 字体大小 |
| ai_mode | AI 推理模式（local/cloud） |
| api_key_cipher | API Key 密文 |
| api_base_url | 云端接口地址 |
| api_model_name | 云端模型名称 |
| local_model_path | 当前本地模型路径 |
| ocr_enabled | OCR 开关 |

### 6.2 文件存储

| 内容 | 存储位置 | 说明 |
|------|----------|------|
| 账单图片 | App 私有目录 | 仅本 App 可访问 |
| 本地 AI 模型 | App 私有目录 | 卸载自动清除 |
| 备份文件（zip） | 公共下载目录 | 用户可访问、分享 |
| CSV 导出文件 | 公共下载目录 | 用户可访问、分享 |

### 6.3 CSV 导入导出（辅助迁移）

- 格式：自有标准格式，表头与账单表字段对应
- 导出：生成 CSV 文件保存至手机公共下载目录，用于查看和跨设备迁移
- 导入：读取 CSV 文件，校验格式后在事务中批量写入，失败回滚
- 定位：辅助手段，不作为主力备份恢复方式
- 不支持第三方账单（微信/支付宝）自动解析导入

### 6.4 备份与恢复

**完整备份（主力方式）**

- 备份内容：SQLite 数据库文件 + 图片文件夹，打包为 zip
- 保存位置：公共下载目录，用户可自行拷贝保存
- 特点：数据零丢失，图片完整保留

**完整恢复**

- 选择备份 zip 文件，校验格式后解压覆盖数据库和图片目录
- 恢复前提示用户将覆盖当前数据，需二次确认

**CSV 导入导出（辅助方式）**

- 用于查看账单明细、向其他设备迁移文本数据
- 不包含图片，图片需通过完整备份恢复

### 12.3 核心技术决策
