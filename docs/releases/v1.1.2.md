# SimpleLedger 1.1.2

## 1.1.2 — 2026-10-17

### 备份增强（短期方案，不含流式）

- 备份弹窗新增“包含图片附件”开关：关闭后只打包数据库，文件通常只有几 MB。
- 备份前展示数据库/完整备份的预估大小。
- 预计超过 512 MB 时直接提示并禁用“开始备份”，需改为仅数据库或先清理附件。
- 仅数据库备份恢复时不再删除现有图片目录；恢复确认文案会区分完整备份与数据备份。
- 新增对应单元测试（备份内容、预估大小、仅数据库恢复保留图片）。
